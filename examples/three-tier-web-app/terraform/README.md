## Assumptions made during generation

- The EC2 instances described are the auto scaling group's members, so they are generated as a launch template rather than standalone hosts.
- Added a VPC (10.0.0.0/16) to host the workload.
- Subnets are spread across 3 availability zones.
- Added a NAT gateway so private workloads have outbound internet access.
- One NAT gateway per AZ (3 total) for high availability.
- Database credentials are stored in Secrets Manager, not in the code.
- Production environment: CloudWatch alarms added for compute and database.
