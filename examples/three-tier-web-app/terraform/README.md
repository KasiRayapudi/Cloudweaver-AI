## Assumptions made during generation

- The EC2 instances described are the auto scaling group's members, so they are generated as a launch template rather than standalone hosts.
- VPC: A load balancer must live in a VPC.
- Public Subnet: An internet-facing load balancer needs public subnets.
- Security Group: The load balancer requires a security group.
- Target Group: A load balancer listener must forward to a target group.
- Security Group: Auto Scaling Group requires a security group.
- IAM Role: Scaled instances need an instance profile role.
- Security Group: The database requires a security group.
- Security Group: The cache requires a security group.
- Route Table: The private subnet needs its own route table.
- NAT Gateway: Compute in the private subnet needs outbound internet access.
- Internet Gateway: A public subnet is only public with an internet gateway.
- Route Table: The public subnet needs a route table with a default route.
- Elastic IP: A NAT gateway requires an Elastic IP.
- One NAT gateway per availability zone (3 total) because high availability was requested.
